# Praktikum Support Vector Machine (SVM)

Folder ini berisi kegiatan latihan untuk memahami penggunaan algoritma **Support Vector Machine (SVM)** dalam pembelajaran mesin. Kegiatan dilakukan melalui beberapa notebook dengan contoh data sederhana dan data nyata.

## Kegiatan yang Dilakukan

1. **Latihan dasar SVM dengan kernel linear**
   - Membuat contoh data sederhana berdasarkan jam belajar dan jam tidur.
   - Menggunakan SVM untuk membedakan data ke dalam beberapa kelompok.
   - Mengamati garis pemisah dan batas antar kelompok pada grafik.

2. **Latihan SVM kernel linear dengan bantuan pustaka**
   - Mengulangi latihan kernel linear menggunakan pustaka pembelajaran mesin.
   - Membandingkan hasil penggunaan SVM yang dibuat secara langsung dengan penggunaan pustaka.
   - Melihat visualisasi batas keputusan yang dihasilkan.

3. **Klasifikasi kemungkinan diabetes**
   - Menggunakan data pemeriksaan kesehatan untuk memprediksi apakah seseorang termasuk kelompok yang terindikasi diabetes atau tidak.
   - Mempelajari data dan melihat hubungan beberapa kondisi kesehatan dengan hasil klasifikasi.
   - Melatih model SVM dan mengukur kemampuan model dalam mengelompokkan data.

4. **Prediksi gaji berdasarkan pengalaman kerja**
   - Menggunakan data lama pengalaman kerja dan gaji.
   - Menerapkan SVM untuk memperkirakan gaji berdasarkan pengalaman seseorang.
   - Membandingkan data asli dengan hasil perkiraan melalui grafik.

## Berkas dalam Folder

- `latihan_svm_kernel_linear_python.ipynb` — latihan dasar SVM dengan kernel linear.
- `latihan_svm_kernel_linear_sklearn.ipynb` — latihan SVM kernel linear menggunakan pustaka.
- `svm_klasifikasi.ipynb` — latihan klasifikasi data diabetes.
- `svm_regresi.ipynb` — latihan prediksi gaji berdasarkan pengalaman kerja.
- `diabetes.csv` — data pemeriksaan kesehatan dan hasil indikasi diabetes.
- `Salary_Data.csv` — data pengalaman kerja dan gaji.

## Tujuan Praktikum

Melalui kegiatan ini, mahasiswa diharapkan dapat:

- memahami gambaran umum cara kerja algoritma SVM;
- membedakan penggunaan SVM untuk klasifikasi dan prediksi;
- mengenali contoh penerapan pembelajaran mesin pada data kesehatan dan data pekerjaan; serta
- membaca dan menafsirkan hasil model melalui tabel dan grafik.
